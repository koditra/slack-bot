# Ash's Right Hand

Ash's Right Hand is a Slack bot with a bunch of small useful and stupid features.

## Features

- `/ash-ping` - Check bot latency
- `/ash-roast @user` - Random roast
- `/ash-dms 7` - View recent DMs
- `/ash-dms reply 1 3 5 Hey!` - Reply to multiple DMs at once
- Reacts with `:67:` whenever someone says `67`
- Randomly says `woof` in threads

Built with Node.js, Slack Bolt, and Socket Mode.
